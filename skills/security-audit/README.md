# Security Audit

**Category:** Engineering | **Version:** 1.0.0

OWASP Top 10 aligned security audit skill. Systematically checks code, configs, and API surfaces for vulnerabilities with severity-ranked output.

## What it does

- Full OWASP Top 10 coverage
- Flags hardcoded secrets, insecure patterns, broken auth
- Checks for vulnerable dependencies
- Produces a prioritized remediation report

## Usage

```
/security-audit
/security-audit src/api/
```
