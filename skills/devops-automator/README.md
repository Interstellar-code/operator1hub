# DevOps Automator

**Category:** DevOps | **Version:** 1.0.0

Reviews CI/CD pipelines, Dockerfiles, and infrastructure configs for correctness, security, and efficiency. Recommends automation improvements and deployment safety patterns.

## What it does

- Audits CI/CD pipelines (GitHub Actions, GitLab CI, etc.)
- Reviews Dockerfiles for size, security, and caching
- Checks IaC (Terraform, Pulumi) for safety and idempotency
- Recommends zero-downtime deployment strategies

## Usage

```
/devops-automator
/devops-automator .github/workflows/deploy.yml
```
